# Stage 3 — Plan Implementation

Create a concrete implementation plan based on repository inspection and architectural assessment.

Identify files to create, files to modify, files that must not be modified, functions/components to add or change, data structures, APIs, UI changes, error handling, security considerations, testing requirements and deployment considerations.

Break the implementation into logical tasks. For each task state the objective, file, implementation, dependencies and validation method.

Do not code until the plan is internally consistent with the repository architecture. Avoid unnecessary abstractions and files.
