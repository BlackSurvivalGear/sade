# Stage 5 — Run Tests

Determine what testing infrastructure exists and run the appropriate tests, type checks, linting, builds, static analysis and application validation.

For frontend changes also verify page loading, assets, JavaScript execution, responsive behaviour, interactions, console errors, links and API failure handling.

For backend changes verify endpoints, validation, errors, authentication/authorization, database operations and external-service failures.

Record each check and PASS/FAIL result. If anything fails, identify the cause, fix it and rerun the relevant checks. Never fabricate test results.
