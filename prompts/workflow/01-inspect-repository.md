# Stage 1 — Inspect Repository

Before making changes, inspect the repository thoroughly enough to understand the current implementation.

Determine the repository structure, entry points, frontend/backend architecture, frameworks, dependencies, data models, APIs, authentication, configuration, build system, tests, deployment configuration, documentation and existing GitHub workflows.

Identify the files relevant to the requested task. Do not modify files during inspection unless required for safe analysis.

Produce an inspection report covering repository overview, relevant files, architecture summary, existing related functionality, dependencies, testing approach, integration points, risks and information still required.

Do not begin implementation until the repository inspection is complete.
