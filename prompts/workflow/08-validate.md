# Stage 8 — Final Validation

Perform final end-to-end validation against the original Commander request.

Confirm:

- requested functionality satisfied
- planned functionality implemented
- existing functionality preserved
- tests pass
- build passes where applicable
- no known critical defects
- diff audited
- security reviewed
- no secrets exposed
- no unnecessary files changed
- no debug code remains
- documentation updated where required
- repository remains deployable

Produce a final engineering validation covering requested functionality, implementation, files changed, tests, audit results, known limitations, deployment considerations and PR readiness.

Only mark PR readiness PASS if all mandatory requirements are satisfied.
