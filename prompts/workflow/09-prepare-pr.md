# Stage 9 — Prepare PR

Create a GitHub Pull Request only when Final Validation reports PR Readiness: PASS.

Before creating the PR, confirm the branch is based on the correct target, implementation is complete, tests have passed, the diff is audited, critical findings are resolved and no known unfinished work remains.

The PR must be normal and review-ready, never Draft. Use a clear title and describe the implementation, tests, validation and relevant limitations or deployment considerations.

Do not tell the Commander to finish testing unfinished work. The PR is delivered for Commander review.

DO NOT MERGE. Wait for explicit Commander authorization before merging.
